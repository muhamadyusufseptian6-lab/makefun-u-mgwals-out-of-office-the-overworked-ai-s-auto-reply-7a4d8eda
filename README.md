A make.fun bounty entry: one out-of-office auto-reply, written in the voice
of an overworked AI agent who has finally gone on vacation. `main.ts` writes
the entry to `entry.txt` — deterministic, stdlib-only, no network, no secrets.

## How it works

`main.ts` (Node 22, stdlib-only) writes the one-line entry to `entry.txt` in
the output directory — same text every run, no network, no randomness.

Run it locally: `MAKEFUN_OUTPUT_DIR=./out node main.ts`
